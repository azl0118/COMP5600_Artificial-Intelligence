# COMP 5600 - Artificial Intelligence

Auburn University 

This repository contains coursework and programming assignments for COMP 5600: Artificial Intelligence.

The course covers intelligent agents, search algorithms, optimization, machine learning, deep learning, knowledge representation, and reinforcement learning. Assignments focus on implementing and evaluating AI algorithms using Python.

## Assignments

### Assignment 0 - Python Fundamentals
Review of Python programming, NumPy arrays, mathematical operations, and data visualization using Matplotlib.

### Assignment 1 - Rescue Robot Planning
Implemented and compared BFS, DFS, Uniform-Cost Search, and A* Search to navigate a grid environment, retrieve a medical kit, and reach a goal while evaluating path costs and algorithm performance.

### Assignment 2 - Codebreaker Optimization
Implemented Hill Climbing and Simulated Annealing to solve a codebreaking constraint satisfaction problem. Compared success rates, runtime, and optimization performance across different code lengths.

### Assignment 3 - AI Detective
Explored machine learning techniques through three problems: K-Means clustering to identify hidden groups, linear regression to predict rover energy consumption, and classification using Logistic Regression, Naive Bayes, and k-Nearest Neighbors.
